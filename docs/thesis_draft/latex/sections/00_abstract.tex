
Question answering over structured public data faces a trust dilemma. Large language models can read natural-language questions but answer unverifiably, while symbolic executors answer verifiably but cannot read. This dissertation presents CICADA, a neuro-symbolic system over a knowledge graph of 215,221 UK public-procurement contract awards. In CICADA the language model only proposes; a deterministic ground--compile--execute--verify stack is the sole answer authority. The central claim is one sentence: \emph{supervision flows only from the verifiable region, yet the learned competence extends beyond it}. All training data is distilled through the pipeline's own verifier and an independent oracle that filters but never authors. Abstention closes the verifier's blind region: three abstention classes are first-class benchmark citizens, and anti-hallucination supervision flows through the same verifier gate. The bootstrapped system runs entirely on a single local GPU, with both the understanding and planning stages served as 8B LoRA adapters. It outperforms its cloud-hybrid counterpart on the held-out test set (n=2,285: 85.65\% vs 78.03\%; +7.61pt, 95\% CI [+6.10, +9.13], McNemar $p<10^{-15}$). It also exceeds its cloud teacher by +15.89pt (69.76\% $\rightarrow$ 85.65\%; CI [+14.07, +17.70], $p<10^{-15}$; single teacher replicate), at zero marginal API cost. Robustness of the teacher gap to provider nondeterminism was checked on the development set, where the student beats each of three teacher replicates (+35/--5, +34/--4, +30/--5; p$\leq$2e-5). De-teachering replicates on a second base (Llama fully-local 83.33\% vs its hybrid 75.97\%; +7.35pt, CI [+5.73, +8.97]); all five pairings hold at $p<10^{-14}$. Mechanistically, across three teacher replicates accuracy decays 6--12 points from the iid to the hard-composite slice. The fully-local student shows no measurable decay (+0.8pt, n=136) with the same planning checkpoint, which we attribute to the distilled understanding stage. All results rest on a 12,828-question benchmark with fully parameterised gold programs, whose oracles are validated by an independent second implementation at 99.88\% agreement.
