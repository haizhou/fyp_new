The \PacsN{}-case test contains 148/149/135/147/127/149/67 examples from F1--F7.  Depth counts are
279 L1, 339 L2, and 304 L3.  Shape exposure is 431 seen and 491 declared unseen.  Operational
status counts are 694 answerable, 138 unsupported, and 90 no-result cases.  Because status
variants travel with their base intent cluster, they do not cross the development/test split.

The sealing implementation uses seed 20260719.  It drops an entire cluster if any of its three
surface candidates exactly collides with a normalised training instruction, relabels status
variants from their actual tree shape, and checks the exact question, tree hash, and unseen-shape
conditions.  For the naturalised channel it computes character-trigram Jaccard similarity
against \texttt{train\_tris[::7]}; this performance shortcut is disclosed because it weakens an
otherwise all-pairs interpretation of the gate.  The console message currently says that G3
passes even though no separate G3 counter is evaluated.  The paper wording follows code, not
that message.

The audit sample selects up to five naturalised instances per family--depth cell and additional
status examples with the same seed.  Before release, a human audit should record literal
preservation, semantic equivalence, answerability, and whether any generated wording is
unnatural or discloses a template artifact.  The current repository contains the sample but not
a complete signed human-audit report.
